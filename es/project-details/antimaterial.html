Antimaterial

Rol: desarrollador frontend y diseñador visual
Proyecto: encargo de cliente independiente

Diseñé y desarrollé Antimaterial, un sitio web multilingüe para una terapeuta finlandesa. Me encargué del diseño visual completo y la implementación frontend desde cero — desde la maquetación y la tipografía hasta un sistema de internacionalización propio en JavaScript que soporta finés, inglés y sueco.

Ver el proyecto: Web en producción

Responsabilidades principales y contribuciones

Diseño visual

  • Diseño de la identidad visual completa del sitio — paleta de color, tipografía, estructura de layout y estilo de componentes, desde cero
  • Creación de una estética calmada y armónica, alineada con la naturaleza terapéutica de la práctica de la cliente
  • Layout responsive para escritorio y móvil sin depender de ningún framework CSS

Sistema multilingüe (i18n)

  • Implementación de un sistema de internacionalización cliente en JavaScript vanilla con soporte para finés, inglés y sueco
  • El cambio de idioma actualiza un atributo data-active-lang en el elemento body, que activa selectores CSS para mostrar u ocultar el contenido etiquetado con data-lang correspondiente — cambio instantáneo sin recarga de página
  • Preferencia de idioma persistida mediante localStorage entre sesiones y páginas
  • Sin librerías externas de i18n — cero dependencias, huella mínima

SEO y metadatos

  • Implementación de metadatos SEO completos: Open Graph, Twitter Card, URL canónica, meta description y directivas robots
  • Contenido multilingüe estructurado para la indexación en los tres idiomas objetivo

Despliegue

  • Desplegado en Cloudflare Pages con configuración por entorno y dominio personalizado
