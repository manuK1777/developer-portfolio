Barcelona Activa IT Academy Challenges

Rol: desarrollador frontend (formación práctica)
Organización: Barcelona Activa IT Academy
Periodo: marzo – abril de 2025

Colaboré en el desarrollo frontend de la plataforma IT Academy Challenges, una aplicación basada en Angular utilizada en el programa IT Academy de Barcelona Activa para ofrecer ejercicios de programación, código inicial y recursos de aprendizaje. La plataforma proporciona interfaces específicas para estudiantes y mentores, permitiendo navegar por retos, gestionar flujos de envío de soluciones y acceder a herramientas de mentoría según el rol.

Ver el proyecto: Código fuente en GitHub

Responsabilidades principales y contribuciones

Arquitectura de la plataforma y UI compartida

  • Trabajo dentro de una arquitectura modular en Angular, con un CoreModule que proporciona componentes de layout (cabecera, menú principal, pie) y módulos de funcionalidad para las áreas de inicio, retos, perfil y mentoría.
  • Contribución a la integración de los módulos de funcionalidad en el AppModule raíz, garantizando que la plataforma se mantuviera fácil de extender a medida que se añadían nuevos tipos de retos y vistas.
  • Uso de Bootstrap y NgBootstrap para el layout y las interacciones con modales, asegurando que las páginas de retos y recursos fueran responsivas en los tamaños de pantalla más habituales.
  • Contribución a componentes compartidos como breadcrumbs, paginación y tarjetas para mantener la navegación y el lenguaje visual consistentes en toda la plataforma.

Descubrimiento de retos y favoritos para estudiantes

  • Implementación de ChallengeCardComponent para presentar cada reto con título, lenguajes, nivel de dificultad, popularidad y contador de favoritos, utilizando @ngx-translate para adaptar las etiquetas al idioma actual.
  • Añadida lógica en la tarjeta de reto para leer y persistir el estado de favorito mediante localStorage, de modo que el alumnado pudiera ver qué retos ya había marcado como favoritos incluso tras recargar la página.
  • Extensión de ChallengeService con métodos simulados addToFavorites y removeFromFavorites que devuelven Observables de RxJS, actualizando las claves is_favorite_{id} y favorites_count_{id} en localStorage y simulando latencia de backend con un pequeño delay.
  • Aseguramiento de que la UX de favoritos se sintiera realista para el alumnado manteniendo al mismo tiempo la seguridad de una ejecución íntegramente en el frontend en entornos de aula o sandbox.

Recorrido del usuario (estudiante) y envío de soluciones

  • Soporte al flujo del estudiante desde el descubrimiento del reto hasta su finalización utilizando ChallengeService para rastrear si un reto se había iniciado mediante un BehaviorSubject y una bandera challengeStarted almacenada en localStorage.
  • Conexión de este estado con la UX de envío de soluciones, de modo que al iniciar un reto se habilitaran los controles adecuados y al abrir el modal de "enviar solución" se reiniciara la bandera de inicio y se llevara al estudiante a un flujo centrado en la entrega.
  • Integración de este comportamiento en componentes basados en modales utilizados para subir o enviar soluciones, manteniendo claro el recorrido del estudiante y evitando estados de UI inconsistentes.

Navegación, breadcrumbs y recursos

  • Uso de BreadcrumbComponent respaldado por BreadcrumbService para generar rutas de breadcrumbs dinámicas (por ejemplo, Inicio ⇒ Retos ⇒ Reto específico), ayudando al alumnado a orientarse al cambiar de vista.
  • Contribución a interfaces compartidas de listado de recursos y retos, incluyendo componentes de tarjeta y paginación, de modo que tanto los ejercicios como los materiales de aprendizaje mostraran metadatos e interacciones consistentes.
  • Garantía de que la navegación y el layout funcionaran bien con la configuración multilingüe de la aplicación (catalán por defecto, con soporte para idiomas adicionales mediante ficheros de traducción y TranslateHttpLoader).

Stack tecnológico y prácticas

  • Angular y TypeScript para la arquitectura de la aplicación y la gestión de estado, complementados con observables de RxJS para el estado compartido de autenticación y retos.
  • HTML5, CSS3, Bootstrap y NgBootstrap para el layout responsivo y las interacciones con modales.
  • @ngx-translate y un I18nModule personalizado para las traducciones y el comportamiento de la UI sensible a la configuración regional.
  • Simulación basada en almacenamiento local para favoritos y estado de retos, desacoplando los ejercicios de frontend de la disponibilidad del backend durante las sesiones de práctica.
