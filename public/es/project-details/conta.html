Conta

Rol: desarrollador backend e ingeniero de herramientas
Proyecto: herramienta de contabilidad por línea de comandos para autónomos en España

Desarrollé Conta, una herramienta de línea de comandos en Python que ayuda a profesionales autónomos a llevar el control de facturas emitidas, gastos deducibles, pagos de seguridad social y obligaciones fiscales trimestrales en España. La aplicación combina un modelo de dominio tipado, persistencia basada en SQLite y comandos orientados a tareas para ofrecer un flujo de trabajo rápido en la contabilidad del día a día.

Responsabilidades principales y contribuciones

Arquitectura de producto y diseño de sistema

  • Diseño de un motor de contabilidad modular utilizando Python 3.10, sqlmodel, pydantic y SQLite para almacenamiento local basado en ficheros.
  • Modelado de las entidades contables principales (FacturaEmitida, GastoDeducible, PagoAutonomo, PagoFraccionado130) con enumeraciones explícitas para los tipos de actividad (programacion, musica).
  • Estructuración de la aplicación como un paquete reutilizable con un punto de entrada conta dedicado y configuración basada en variables de entorno.

Experiencia de CLI y automatización de flujos

  • Implementación de una CLI multi-comando usando Typer, con ayuda estructurada y parseo de argumentos adaptado a los flujos fiscales españoles.
  • Añadidos comandos para registrar facturas emitidas (emite), gastos deducibles (gasto), pagos de seguridad social de autónomos y pagos fraccionados de IRPF.
  • Salida enriquecida en terminal utilizando la librería Rich, incluyendo listados tabulares de facturas y gastos.
  • Inclusión de validaciones y mensajes de error útiles para fechas, campos numéricos y formatos de trimestre, reduciendo errores de usuario.

Lógica fiscal y de reportes para autónomos en España

  • Encapsulado del cálculo trimestral de IVA en un servicio dedicado, calculando el IVA devengado y deducible por trimestre.
  • Implementación de la lógica de snapshot acumulado de IRPF, alineada con la estructura del Modelo 130 (base, retenciones, pagos previos) a través del servicio irpf_snapshot_acumulado.
  • Consideración de cuotas de seguridad social, pagos fraccionados previos y filtros por actividad para ofrecer una visión realista de las obligaciones trimestrales de IRPF.

Modelo de datos y persistencia

  • Uso de SQLModel para definir tablas tipadas con índices en fechas y números de factura para un filtrado e informes eficientes.
  • Garantía de operaciones idempotentes para entidades críticas (por ejemplo, evitando números de factura duplicados en la creación).
  • Gestión de una base de datos SQLite ligera, inicializada mediante un único comando conta init.

Exportaciones, copias de seguridad y extensibilidad

  • Exportación a CSV de los libros oficiales de IVA utilizando pandas, generando ficheros separados de facturas emitidas y recibidas por trimestre.
  • Añadido un comando backup-db para crear copias con marca temporal de la base de datos SQLite para archivado seguro.
  • Implementación de hooks de importación de PDFs de facturas, sentando las bases para automatizar la entrada de datos desde documentos escaneados.
  • Estructuración del proyecto con dependencias de FastAPI y Uvicorn para permitir una futura evolución desde una CLI pura a un pequeño panel web sin cambiar la capa de dominio.
