Extended Bandoneon

Rol: desarrollador web full-stack – diseñador de producto
Proyecto: plataforma artística independiente

Diseñé y desarrollé Extended Bandoneon, una plataforma multimedia full-stack dedicada a documentar y sistematizar técnicas extendidas avanzadas de bandoneón. La aplicación combina contenido de investigación estructurado, medios incrustados y un banco de sonidos curado en un archivo digital escalable construido con tecnologías web modernas.

Ver el proyecto: Código fuente en GitHub — Sitio web en producción

Responsabilidades principales y contribuciones

Arquitectura de producto y diseño de sistema

  • Arquitectura de la aplicación full-stack utilizando Next.js, React, TypeScript y Tailwind CSS.
  • Diseño del esquema relacional de base de datos MySQL para técnicas, artículos, sonidos y usuarios.
  • Estructuración de una arquitectura de App Router escalable alineada con los estándares modernos de Next.js.
  • Planificación de una estrategia de despliegue optimizada para la infraestructura de Vercel.

Arquitectura de UI e ingeniería frontend

  • Creación de interfaces responsivas y accesibles con HTML semántico y estructura alineada con WCAG.
  • Diseño de un sistema de UI reutilizable basado en componentes.
  • Implementación de enrutado dinámico para las páginas de detalle de técnicas y artículos.
  • Integración de contenido multimedia incrustado (demostraciones en video y previsualizaciones de audio).

Plataforma de contenido e investigación

Módulo de técnicas extendidas

  • Desarrollo de un escaparate estructurado para técnicas extendidas de bandoneón.
  • Creación de páginas dedicadas con descripciones, imágenes de apoyo y demostraciones incrustadas.
  • Implementación de una arquitectura de URLs optimizada para SEO que mejora la descubribilidad del contenido.

Sistema de artículos académicos y de investigación

  • Construcción de la interfaz de listado de artículos.
  • Implementación de páginas de artículo detalladas con resumen, contenido completo y descarga en PDF.
  • Estructuración del modelo de contenido para una futura integración con CMS.

Banco de sonidos

  • Diseño de un archivo de sonidos escalable con paginación basada en cursores e infinite scroll.
  • Implementación de filtrado por etiquetas multi-selección con sistema de clasificación buscable y taxonomía relacional.
  • Integración de un reproductor de audio personalizado con carga diferida para una renderización de medios optimizada.
  • Construcción de un sistema de descarga de audio en múltiples formatos con streaming de blobs en cliente y feedback de UX.
  • Generación de datos estructurados dinámicos con schema.org (JSON-LD) para mejorar la indexación en buscadores.

Podcast

  • Desarrollo de una página dedicada al podcast con una lista ordenable de episodios y reproductores de audio incrustados.
  • Estructuración de metadatos y maquetación para alinear el contenido del podcast con el ecosistema general de investigación y banco de sonidos.

Panel de administración y gestión de contenido

  • Desarrollo de un panel de administración protegido para gestionar el contenido de la plataforma.
  • Implementación de una arquitectura modular de panel con componentes cargados dinámicamente.
  • Creación de una interfaz de subida de sonidos para gestionar los recursos de audio.
  • Estructuración de un sistema preparado para futuras funcionalidades de gestión de artículos y técnicas.
  • Integración de un flujo de cierre de sesión autenticado y rutas protegidas.

SEO y optimización de rendimiento

  • Implementación de Server-Side Rendering (SSR) y Static Site Generation (SSG).
  • Estructuración de metadatos utilizando la Next.js Metadata API.
  • Aplicación de datos estructurados schema.org para artículos y contenido multimedia.
  • Optimización de la carga de medios con lazy loading y estrategias modernas de imágenes.

Autenticación y escalabilidad futura

  • Diseño de la arquitectura de registro e inicio de sesión con autenticación segura por email/contraseña y flujo de verificación por correo electrónico.
  • Planificación del control de acceso basado en roles para usuarios públicos y administradores.
  • Preparación de la estructura del sistema para futuras herramientas de audio interactivas y cuentas de usuario.

Despliegue y flujo de trabajo

  • Estructuración del proyecto para el despliegue en Vercel.
  • Implementación de gestión de configuración basada en entornos.
  • Mantenimiento de una base de código limpia y escalable.
